# 顾明泱作品集网站

直接打开 `index.html` 即可预览首页；`archive.html` 是保留的完整作品档案。网站为纯静态版本，不依赖安装环境或在线字体。

线上地址：`https://18016430978-ai.github.io/gu-mingyang-portfolio/`

手机扫码材料：

- 高清二维码：`assets/portfolio-qr.png`
- 面试打印 / 投屏卡片：`qr-card.html`
- 二维码始终指向线上地址，后续更新网站内容时无需重新生成。

## 内容

- 首页采用纯文字项目索引，项目内容仅以悬停空浮窗提示，不固定铺设作品图片
- 点击任一项目进入统一的 `project.html?id=项目` 详情模板；介绍页保持在下层，纯白作品长页从下方圆角覆盖上来
- 每个详情页使用独立封面，并按作品集原始顺序连续展示 2560px WebP 高清展板，展板之间仅保留 6—8px 间距；离屏展板按需加载与渲染
- “金陵雨花石录”拆分为信息可视化与交互装置两个独立项目，并新增“唐三彩 · 文旅网页设计”，共 10 个项目、35 页高清展板
- “金陵雨花石录 · 交互装置”“自然色差”和“瞳趣”在最后一张展板后嵌入项目视频，可直接播放、暂停、拖动和全屏；线上视频统一为经 Microsoft Edge 实测的 1080p VP9/Opus 网页兼容版，并在用户点击播放前不预载视频数据
- 首页悬停预览与档案页浮窗统一使用 `作品集网站.rar` 中的 10 张项目缩略图
- 小字号正文与履历说明统一采用约 `1.4` 倍行距；设计方法更新为“洞察 / 实验 / 构建 / 演进”
- 全站文案以中文为主，栏目、专业方向和操作标签采用克制的中英混排
- 首页 GU/MY 身份首屏、固定顶部导航、推页式菜单与设计网格
- 首页中部采用纵向履历摘要，右下角以黑白个人照片替代原条纹图形
- 首页右上角六项索引、GRID 设计网格覆盖层、项目 PREV / NEXT 控制和推页式索引菜单均可点击
- 桌面端项目标题悬停／键盘聚焦作品浮窗，手机端自动关闭以避免遮挡
- 手机端展板使用独立的 960px WebP 资源并按滚动位置加载；原始 2560px 展板仍供桌面端使用
- 三个项目视频优先播放 540p H.264/AAC 快速起播版，原 1080p WebM 仅作为兼容回退
- 首页、档案页与详情页的样式和脚本带版本号，发布新版本后可避免微信内置浏览器继续使用旧缓存
- 图片加载异常会自动重试，档案页只初始化当前视口附近的项目，减少首次打开请求数
- 设计令牌、设计说明与独立设计系统预览页

## 发布

整个文件夹可直接在本地或静态服务器运行。不要只上传 `index.html`，需要连同 `assets`、样式与脚本文件一起上传。GitHub Pages 部署版只保留网页兼容视频，以符合 GitHub 单文件大小限制并减少加载时间。
